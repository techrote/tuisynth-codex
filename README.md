# TRIO autonomous synthesizer implementation

This repository is one independent implementation attempt of the **TRIO** terminal-synthesizer programme.

The implementation programme is issue-driven. Start with `docs/programme/IMPLEMENTATION-PROGRAMME.md`, then read `AGENTS.md`, `ATTEMPT.md`, and `docs/rag/INDEX.md`.

No synthesizer implementation is present in the seed. The assigned provider owns the complete programme from foundation through release qualification.
