# Mandatory regression lessons
| Historical failure | Required defense |
|---|---|
| identical package names | unique co-installable distributions/imports |
| discrete morph interpolation | discrete/choice switch at t=0.5 with boundary tests |
| NaN/Inf/wrong types reached DSP | strict validation/domain errors |
| malformed preset/theme crashes | hostile-input loaders/tests |
| transpose/same-pitch note-off bugs | stable note_id ownership + overlap tests |
| render tails/unwritten callback output | arbitrary-chunk equivalence + initialized outputs |
| reversed delay | chronological impulse/ramp regression |
| untested limiter/safety claims | hot-input ceiling + nonfinite tests |
| asynchronous UI->DSP mutation | queued events + block snapshots |
| lifecycle cleanup crashes | null fallback + shutdown ordering tests |
| invalid MIDI values | constructor/parser validation |
| SGR mapping bug | real SGR injection across hit regions |
| unused registered controls | per-instrument parameter-usage coverage |
| wheels missing assets | explicit package data + clean-venv wheel tests |
| lost model provenance | role-based provenance |
| normalized red baseline | never weaken tests or merge required red checks |
